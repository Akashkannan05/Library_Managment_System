# Library Management System

This project is a basic library management system written in Python. It interacts with a MySQL database to manage book records, allowing a librarian to perform tasks such as adding records, listing books by author, checking book availability, returning books, and more.

## Features
1. **Add a New Book Record**: Add details such as book name, author, student name, return date, cost, and number of copies.
2. **List Books by Author**: View all books by a specific author.
3. **Check Book Availability**: View the number of copies available for a specific book.
4. **Return a Book**: Mark a book as returned.
5. **View Books Not Returned**: View details of all books that have not been returned.
6. **Exit**: Exit the system.
